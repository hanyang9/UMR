Interactive browser application

UMR Motion Retargeting Studio

Upload an MJCF robot, edit its T-pose, select a reference motion, and run sampling, correspondence training, mesh binding, and retargeting locally in this browser.

!

Important usage note

This Studio is an interactive visualization experience. Due to data license, retargeted results are not available for download. It runs a complete UMR pipeline adapted specifically for the browser—from surface sampling and correspondence training through mesh binding and retargeting. To maximize accessibility across devices, training runs on the CPU. Online Studio performance is not representative of native UMR performance.

Memory requirement: keep at least 3 GiB of memory available before running a task.
